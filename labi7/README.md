# ЛПР 7

Компонент `MyForm` содержит шесть полей. После нажатия **Sign in** появляется таблица со значениями, отсортированными по именам полей. Кнопка **Back** возвращает форму с сохраненными данными.

## Запуск

Нужен установленный Node.js (версия 22.12 или новее).

Откройте PowerShell в папке `labi7` и выполните:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте в браузере адрес, который появится в терминале (обычно http://localhost:5173).

Чтобы остановить приложение, нажмите **Ctrl+C** в терминале.

## Проверка сборки

```powershell
npm.cmd run build
```
